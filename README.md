# Site — Giovanna Rimkus | Psicologia Clínica

Este projeto é um site institucional para apresentar a psicóloga Giovanna Rimkus, com foco em comunicação clara, acolhimento e profissionalismo.

## O que é o projeto
O objetivo do site é divulgar a atuação de Giovanna Rimkus como psicóloga clínica, apresentando:
- sua identidade profissional;
- informações sobre a abordagem terapêutica;
- diferenciais do atendimento;
- formas de contato para agendamento.

A página foi desenvolvida com React + Vite + Tailwind CSS, com visual moderno e voltado para uma experiência suave em dispositivos móveis e desktop.
